ABSTRACT
In today’s highly interconnected world, network security is a critical
challenge for enterprises when storing and transmitting sensitive
information. Traditional security measures are increasingly inadequate against the ever-growing complexity of network attacks. This
paper aims to design and implement a machine learning-based Network Intrusion Detection System (IDS) to enhance the accuracy and
defense capability against network attacks. Using the CICIDS2017
dataset, the study employs Stacked Autoencoders (SAE) for data
dimensionality reduction and feature extraction, followed by intrusion detection utilizing the Random Forest (RF) classification
algorithm. Experimental results demonstrate that the system excels
in detecting various types of network attacks, particularly DDoS,
Brute Force, and Botnet attacks, achieving an accuracy of 98.5%,
with precision and recall rates both exceeding 97%. The system incorporates a feedback mechanism, enabling adaptive adjustments to
the ever-changing network environment, thereby providing robust
security assurance. The findings validate that the proposed method
significantly improves the accuracy and robustness of intrusion
detection.

INTRODUCTION

In today’s highly interconnected world, cybersecurity is a significant challenge for enterprises when storing and transmitting critical
information. As the complexity of online threats continues to grow,
traditional security measures are increasingly becoming inadequate.
Intrusion Detection Systems (IDS) play a crucial role in detecting
and preventing system attacks by monitoring system traffic and
identifying abnormal or malicious activities. Automated learning
techniques have garnered attention for their ability to recognize
complex, previously undetected attacks, particularly strategies that
integrate multiple classifiers to enhance detection robustness and
accuracy. High-quality training data is essential for accurately
capturing the characteristics of network attacks.

2

CICIDS2017 DATASET

To effectively defend against network attacks, the implementation of Intrusion Detection Systems (IDS) and Intrusion Prevention
Systems (IPS) is indispensable. However, anomaly-based intrusion detection methods often face the challenge of lacking reliable
test and validation datasets. Many existing datasets suffer from
deficiencies in diversity and volume of network traffic, failing to
comprehensively cover all known types of attacks. Additionally,
some datasets lack important features and metadata, limiting the
potential for in-depth research.
The CICIDS2017 dataset, released by the Canadian Institute for
Cybersecurity (CIC) at the University of New Brunswick, aims
to provide a real-world, high-quality network intrusion detection
dataset. This dataset covers a variety of network attacks and normal
traffic generated in 2017, exhibiting high diversity and data volume
[1]. The CICIDS2017 dataset includes multiple types of network
attacks, including but not limited to the following categories:
DoS (Denial of Service Attack): Exhausting target resources with
numerous requests, rendering normal services unavailable.
DDoS (Distributed Denial of Service Attack): DoS attacks initiated from multiple sources simultaneously.
Brute Force Attack: Attempting to crack system account passwords through exhaustive methods.
Heartbleed: Exploiting the Heartbleed vulnerability to steal sensitive information.

Each type of attack is accompanied by detailed traffic records,
encompassing various network features such as source IP address,
destination IP address, source port, destination port, protocol type,
packet size, and more. Additionally, the dataset provides timestamps and labels for the traffic, distinguishing between normal
traffic and different types of attack traffic.
The diversity of the CICIDS2017 dataset is reflected in its inclusion of multiple types of attacks and normal network traffic.
The dataset generation process simulates various use scenarios in
real-world network environments, including internal enterprise
networks, internet access, mail servers, database servers, and more.
The traffic patterns in these scenarios vary, reflecting network behaviors in real environments.
The dataset’s extensive coverage includes not only common network attack types but also some complex and advanced attacks,
such as APT (Advanced Persistent Threat) and zero-day attacks [2].
These attacks are typically difficult to detect, and the CICIDS2017
dataset provides valuable data resources for studying these advanced attacks.

SYSTEM DESIGN AND IMPLEMENTATION

The proposed network intrusion detection system is composed of
five main components: the preprocessing component, the autoencoder module, the data module, the classification module, and the
feedback module. [3] Together, these components form an efficient and accurate intrusion detection framework. The framework
diagram is shown in Figure 1.

3.1

Preprocessing Component

The preprocessing component serves as the foundation of the intrusion detection system, responsible for cleaning and standardizing
raw network traffic data to facilitate subsequent processing and
analysis. The preprocessing process includes data cleaning, data
normalization, and data segmentation.

138

• Data Cleaning: This step removes noise and outliers from the
dataset, ensuring data accuracy and consistency. Key methods include handling missing values, removing duplicate
records, and correcting erroneous data.
• Data Normalization: This step scales the data features to the
same magnitude, eliminating differences in scale between
different features. Common methods include z-score normalization and min-max scaling.
• Data Segmentation: The dataset is divided into training, validation, and test sets to ensure the reliability and effectiveness
of model training and evaluation.
Through these preprocessing steps, the raw data is transformed
into standardized training and validation sets, providing a highquality data foundation for subsequent feature extraction and classification.

3.2

Autoencoder Module

The autoencoder module employs stacked autoencoders (SAE) for
data dimensionality reduction and feature extraction. SAE consists
of multiple layers of autoencoders (AE) stacked together, which
encode input data into low-dimensional representations and then
decode them into approximations of the original data, capturing
the latent feature structure of the data.
An autoencoder is an unsupervised learning model comprising
two main parts: the encoder and the decoder. The encoder compresses the input data into a low-dimensional representation, while
the decoder reconstructs the low-dimensional representation back
into an approximation of the original input. By minimizing the
reconstruction error between the input and output, the autoencoder
learns the key features of the data [4].
Stacked autoencoders (SAE) further enhance feature extraction
capabilities by cascading multiple AE layers, capturing complex
nonlinear relationships.

Feedback Module

The feedback module is used to evaluate the performance of the classification module and utilize feedback information for continuous
system optimization and improvement. Its main functions include
model evaluation, model updating, and system optimization.
Model Evaluation: Assess the classifier’s performance using
various evaluation metrics such as accuracy, precision, recall, and
F1 score.
Model Updating: Regularly update and retrain the classifier
based on evaluation results to adapt to new network traffic patterns
and attack methods.
System Optimization: Adjust various system modules based on
feedback information to improve overall performance.

CLASSIFICATION TECHNIQUES

In this study, classification techniques are one of the core modules
for data analysis and prediction. The Random Forest (RF) algorithm
will be selected as the primary classification method. Random
Forest is an ensemble learning method that improves classification
performance by constructing multiple decision trees and combining
their prediction results [5].

Random Forest Algorithm

Random Forest generates multiple decision trees, each of which is
created from a random subset of the training data. Randomness is
also introduced in feature selection and data splitting. Compared to
a single decision tree, the advantages of Random Forest are mainly
reflected in the following aspects:
Reduction of Variance: As the number of trees in the forest
increases, the model’s variance decreases while the bias remains
unchanged [6]. This allows Random Forest to effectively prevent
overfitting and generalize better to new data.
Simple Parameter Tuning: Random Forest requires fewer parameters to be tuned, making it more convenient and efficient in
practical applications.
Robustness: Due to the ensemble decision of multiple trees,
Random Forest exhibits high robustness to noisy data and outliers.
Algorithm 1: CART Algorithm
For the use of decision trees, the CART (Classification and Regression Trees) algorithm is employed. The CART algorithm splits
the data into left and right subtrees using a binary method, where
each non-leaf node has two child nodes, forming a binary tree structure. The core of CART classification lies in selecting the optimal
features for data splitting, which is achieved by calculating the Gini
index.

In the CART algorithm, the decision tree is generated through the
following steps:
Step 1: Start from the root node and calculate the current node’s
Gini index.
Step 2: For each feature A and its possible split points a, calculate
the Gini index.
Step 3: Select the feature and split point with the smallest Gini
index for data splitting.
Step 4: Recursively perform the above steps for each child node
until the stopping criteria are met.

The generating tree classifier is a classification method based on

Check if the number of trees to be generated is less than N. If so,
proceed with the following steps:
Randomly sample S samples from the S training samples with
replacement to form a new training set. This sampling method
ensures that each tree has a different dataset, enhancing the model’s
generalization ability [8].
Use the unselected samples (called Out-Of-Bag (OOB) samples)
for prediction and evaluate the model’s error rate. This step assesses the model’s generalization performance and may be used for
subsequent adjustments.
For each node, randomly select mm features. This step introduces
randomness, reducing the correlation between features and further
improving the model’s generalization ability.
Calculate the optimal split for each of the selected m features.
Typically, the optimal split point is determined using metrics such
as the Gini index or information gain.
Grow the tree to its maximum possible extent without pruning.
This means each tree is fully grown, with no depth restriction, to
maximize the tree’s fit to the training data.
Repeat the above steps until N trees are generated, ultimately
forming a complete tree classifier.

EXPERIMENTAL RESULTS

To evaluate the effectiveness of the proposed benchmark in both
binary and multi-class classification problems, and to assess the
effectiveness of the methods proposed in this study for identifying small-scale features, experiments were conducted on the CICIDS2017 dataset. The test and training times were calculated to
evaluate the efficiency and capability of the models. When using
multiple parameters (here, considering Decision Trees (DT) as a
model for Random Forests (RF)), these techniques performed well
in both binary and multi-class classification problems [9].
In the binary classification problem, traffic is categorized into
benign and pathological. Table 1 summarizes the performance of
various models in the binary classification task, including accuracy,
precision, recall, and F1 score.
From Table 1, it can be seen that as the number of trees in the
Random Forest model increases, the model’s performance improves
significantly across all evaluation metrics. The RF-110 tree model
performed the best in terms of accuracy, precision, recall, and F1
score, demonstrating its strong capability in binary classification
tasks. For example, the RF-20 tree model achieved an accuracy
of 98.12%, precision of 97.23%, recall of 98.87%, and F1 score of
98.04%. In contrast, the RF-110 model improved its accuracy to
99.02%, precision to 98.43%, recall to 99.28%, and F1 score to 98.85%.
In the multi-class classification problem, the models’ ability to
identify 15 different types of attacks was evaluated. Despite the
smaller sample sizes for certain attack types (such as Infiltration,
Heartbleed, and SQL Injection), the proposed method was able to
accurately identify these types of attacks. Table 2 summarizes the
performance evaluation results for the multi-class classification
problem.
Table 2 illustrates the models’ ability to identify 15 different
