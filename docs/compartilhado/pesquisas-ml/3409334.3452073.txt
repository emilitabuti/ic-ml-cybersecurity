ABSTRACT

1

Network security is an important aspect for any organization to
keep their information systems secure. A Network Intrusion Detection System (NIDS) is an aid to secure the network by detecting
abnormal or malicious traffic. In this paper, we applied a Semisupervised machine learning approach to design a NIDS. We implemented semi-supervised Support Vector Machine (SVM) and
semi-supervised Random Forest (RF) classifiers to classify the NSLKDD dataset. We have classified the dataset in both binary and
multiclass. We have also implemented a Genetic Algorithm (GA)
approach to select the optimal features from the original features
set. Results show that the random forest algorithm produces a better
result than SVM using semi-supervised learning method. Also, the
results show that applying the GA in SVM produces a better result
than without using GA, and so does using GA in Semi-supervised
Random Forest.

As the use of computer networks increases, the importance of intrusion detection is also increasing. Machine learning approaches have
been applied to implementing intrusion detection systems (IDS). An
IDS can be categorized as Host-based Intrusion Detection Systems
(HIDS) or Network-based Intrusion Detection Systems (NIDS) determined by its position of placement over the network system [2].
In this experiment, NIDS is applied. The learning approach could
be supervised, unsupervised, or semi-supervised. A fully labeled
training dataset is used in a supervised learning technique. In the
unsupervised learning technique, an unlabeled training dataset is
used for classification. Semi-supervised learning lies in between
the supervised and the unsupervised learning approach, where a
small chunk of labeled training data is used as the training dataset
to train the model and label the rest of the unlabeled data.
Researchers have used semi-supervised learning for intrusion
detection. Shi, Yuan, and Nick [14] performed semi-supervised Support Vector Machine (SVM), Random Forest, and Deep Belief Network (DBN) using KDD 1999 dataset, and concluded that random
forest generates better results than SVM in semi-supervised learning. According to Muhuri et al. [7], using Genetic Algorithm (GA)
on the dataset produces a higher accuracy on NSL-KDD dataset
in multiclass classification than applying Long short-term memory recurrent neural network LSTM-RNN classifier. Applying GA
improved the classification accuracy of SVM and RF also.
In this experiment, we have implemented an intrusion detection
system using semi-supervised learning techniques on NSL KDD
data. We did experiments on semi-supervised SVM and Random
Forest, as well as applying GA to select optimum features before using semi-supervised SVM and Random Forest classifiers. We found
that using GA to select optimum features improved classification
performance in semi-supervised learning with SVM and Random
Forest classifiers.

2 BACKGROUND
2.1 Semi-supervised Learning Method
In supervised learning, a fully labeled data is used for training. In
unsupervised learning, totally unlabeled data is used for training.
Normally the larger the number of training samples, the better the
performance of the classifier. Semi-supervised learning uses both
labeled and unlabeled data for training. Assuming the classifier
model is correct, and the additional samples are of good quality, the
issue of semi-supervised learning is to improve supervised learning
by adding unlabeled data or determining what information can be
obtained from unlabeled data to improve supervised learning [1].

Support Vector Machine

Support Vector Machine (SVM) is a machine learning algorithm
that can be used to perform linear regression and classification.
SVM performs these tasks by creating a hyperplane between the
different data points to distinguish data with different features. A
hyperplane is an imaginary line between the data which classifies
the different data points. The hyperplane created can be single
dimensional or multidimensional depending upon the number of
classes. Hamid, Sugumaran, and Ranganathan [2] described that
maximizing the margin and thereby creating the largest possible
distance between the separating hyper-plane and the instances
on either side of it has been proven to reduce an upper bound on
the expected generalization error. Özgür and Erdem [10] mentions
that Support Vector Machine are the most applied Algorithm while
performing Intrusion Detection System.

related to them.
A decision tree is a non-parametric and nonlinear data mining
approach used for supervised classification learning and regression

evolution. GA is based on the theory of “survival of the fittest”.
Genetic algorithm is the process of natural selection where the
fittest members are selected for the further generation. The GA is
a particular case of Evolutionary Algorithms which are based on

Accuracy is the percentage of correctly classified records over
the total number of records.
Precision is the ratio of records correctly classified as attacks
over the total number of records classified as attacks.
Recall is the ratio of records correctly classified as attacks over
the total number of actual attacks.
F1-score is the harmonic mean (in percentile) of precision and
recall [7].

Discussion

While performing binary classification, both SVM and Random Forest give an accuracy of 100%. Similarly applying Genetic Algorithm
to the experiments also provides an accuracy of 100%. So, we can
conclude that semi-supervised Random Forest and semi-supervised
SVM both work well for binary classification. Whereas using Semi
Supervised SVM for multiclass classification, we get an accuracy of
67.5% and after applying genetic algorithm to it, we have obtained

RELATED WORK

Researchers have done similar experiments using semi-supervised
learning with different modules like support vector machine, random forest, Deep belief Network (DBN). Shi et al. [13] performed
semi-supervised support vector machine algorithm using KDD1999
dataset, and have achieved a highest accuracy of 85.2% while performing multiclass classification. Shi, Yuan, and Nick [14] have also
performed a semi-supervised random forest module with KDD1999.
Nadeem et al. [8] have performed semi-supervised learning using Deep belief network module Ladder Network on KDD1999 for
binary classification. We performed semi-supervised learning on
NSL-KDD dataset, which removed duplicated data from KDD 1999.
Our semi-supervised approach is similar to Shi et al. [13]. Muhuri
et al. [7] conducted supervised learning on NSL-KDD using LSTMRNN Classifier. They used GA to select optimum features and use
these selected features with LSTM-RNN. They found that using
GA produces a higher accuracy on NSL-KDD dataset in multiclass
classification than applying LSTM-RNN classifier only. We applied
the same GA to select optimum features of NSL-KDD, and then use
these features for semi-supervised learning with SVM and RF. We
also found using GA in the semi-supervised approaches improved
classification accuracy compared with not using GA.
Adankon and Cheriet have used Genetic algorithm while performing Semi-supervised SVM on different sets of data as followed:
Gaus50, Guas50x, Text and USPS [1]. They have applied GA with
a similar concept as we did but for a different purpose. In our
experiment, we have applied GA to the training dataset while preprocessing the data before applying any of the algorithm whereas
Adankon and Cheriet have first applied SVM and then applied GA
to it [1]. Leistner, Saffari, Santner, and Bischof [5] have performed
semi-supervised SVM and Random forest on different datasets like
g50c, Letter, SensIt. They have introduced a novel algorithm for
semi-supervised learning with random forests.
